# Law Journal Workbench — Editor Preview

This public repository distributes tested desktop builds of Law Journal
Workbench. The application assists law-journal editors with citation-form
review, source organization, pincite evidence, and review workflow while
leaving final editorial judgment with the editor.

## Download

Use the editor-friendly download page:

**https://aintfunny18-tech.github.io/law-journal-workbench-releases/**

The page provides separate downloads for Windows and Apple Silicon macOS, a
link to the web edition, and plain-language installation instructions.

## Privacy

Desktop projects, manuscripts, and source libraries remain on the editor's
computer. The hosted web edition must receive selected documents for
processing; use the desktop edition when local-only handling is important.

## Scope

Law Journal Workbench is an editor-assistance tool. It does not replace
Bluebook judgment, source review, substantive legal analysis, or an editor's
final decision. Missing-source and Manual check labels identify limitations in
available evidence and do not necessarily mean a citation is incorrect.
