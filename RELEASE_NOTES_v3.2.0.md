# Law Journal Workbench v3.2.0 — Editor Preview

Law Journal Workbench helps law-journal editors organize the mechanical first
pass of citation review while preserving editorial judgment.

## Choose one download

- **Windows 10/11:** `LawJournalWorkbench-v3.2.0-Windows.zip`
- **Apple Silicon Mac (M1, M2, M3, M4, or later):**
  `LawJournalWorkbench-v3.2.0-macOS-Apple-Silicon.zip`
- **Intel Mac:** use the web edition for this release.

Each ZIP contains a `START_HERE` file with platform-specific instructions.

## Highlights

- Quick Citation Audit for project-free citation-form review.
- Local project dashboards and reusable source libraries.
- Full Source Check readiness preview before processing begins.
- Resizable citation-results cockpit with findings, source evidence, and
  editor decisions.
- Reporter-specific page matching for parallel reporters.
- Footnote and endnote extraction.
- Common non-case citation checks, including statutes, regulations, public
  laws, law-review articles, database citations, and administrative decisions.
- Light and dark themes with three text-size choices.

## Privacy and limitations

Desktop projects, manuscripts, and source libraries remain on the editor's
computer. Suggestions are read-only and do not silently rewrite uploaded
documents. Law Journal Workbench assists with citation review; it does not
replace Bluebook judgment, source review, or substantive legal analysis.

The macOS build is for Apple Silicon and is not Apple-notarized. The included
`START_HERE - macOS.txt` explains the expected first-launch warning and Apple's
Privacy & Security procedure without requiring Terminal commands.
